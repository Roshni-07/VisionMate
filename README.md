# VisionMate
AI-Powered Assistive System for Dementia and Visual Impairment
BMSIT&M | Interdisciplinary Project 2025-26

## Files
- server.py          — Flask backend (AI processing)
- visionmate_app.html — Frontend app (open in phone Chrome)
- requirements.txt   — Python dependencies
- Procfile           — For cloud deployment
- render.yaml        — Render.com config

## Local Setup
pip install -r requirements.txt
python server.py

## Deploy to Render.com
1. Push this folder to GitHub
2. Go to render.com → New Web Service → Connect repo
3. Done — get your public URL

## Use on Phone
Open Chrome → go to your-server-url/app
